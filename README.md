
# 💍 Wedding Music Playlist

## 📌 Project Description
Wedding Music Playlist is a simple and interactive web application developed using HTML, CSS, and JavaScript. It provides a beautiful wedding-themed interface where users can listen to their favourite wedding and romantic songs.

The background image changes according to the selected song, creating a pleasant and personalized music experience.

## ✨ Features
- Beautiful wedding-themed background.
- Collection of wedding and romantic songs.
- Play selected songs.
- Background image changes when selecting a song.
- Simple and user-friendly interface.
- Responsive design.

## 🛠️ Technologies Used
- HTML – To create the webpage structure.
- CSS – To design and style the interface.
- JavaScript – To handle song selection, audio playback, and background changes.

## 🚀 How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html in your browser.
4. Select your favourite song and enjoy the music!
